# tg-super-backend

Serverless Telegram support bridge. Customers contact a product bot; managers work in mapped topics of that product's private forum group.

Prototype work is tracked in [GitHub Issues](https://github.com/tryproxy/tg-super-backend/issues?q=is%3Aopen+label%3Aprototype). Current project context: [decisions](_docs/decisions.md), [open questions](_docs/open-questions.md), [tech stack](_docs/tech-stack.md), and [work process](_docs/process.md). Prototype criteria P-01–P-19 are in the [archived plan](_docs/archived/plan.md); other completed planning material is in [_docs/archived/](_docs/archived/).
